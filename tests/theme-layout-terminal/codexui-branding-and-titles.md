# codexui 1.1.0 页面品牌与标题

## 前提

- 当前仓库页面服务已由人工启动，验收地址 `http://127.0.0.1:4173/`。
- 分别使用浅色、深色及 `1440×1000`、`768×1024`、`375×812` 视口。
- 浏览器自动化按当前会话约定执行；使用隔离上下文和受控 API 数据，不写入真实会话。

## 操作与预期

| 操作 | 预期 |
| --- | --- |
| 访问首页，展开侧栏 | 页面标题为 `codexui`；设置按钮旁显示 `codexui · v1.1.0`，不以工作树目录名充当产品名 |
| 打开设置 | 诊断行仍显示 `WT <工作树名称> · v1.1.0`，方便区分源码目录 |
| 打开有标题的会话 | 浏览器标题为 `<会话标题> · codexui`；回首页后恢复 `codexui` |
| 打开无标题的会话 | 回退为 `codexui`，不显示 hostname 或上一会话标题 |
| 进入 Skills 和 Automations，再切换界面语言 | 标题为 `<当前语言的页面名> · codexui`，不残留会话标题 |
| 查看首页新功能提示、登录页、反馈邮件主题及前端资源缺失页 | 均使用 `codexui`；真实 Codex CLI/provider 名称不受影响 |
| 检查 `/manifest.webmanifest` 及 Apple 安装名 | `name`、`short_name` 和 Apple 安装名均为 `codexui`；图标、start_url 和 scope 不变 |
| 设置主题和语言，输入未发送草稿后刷新 | 主题、语言、草稿保持，继续使用原 localStorage 键；不要发送草稿 |
| 各视口等待 2–3 秒后截图 | 品牌、版本文字可读，无裁切、重叠和水平溢出；深色页面没有新引入的浅色背景 |

## 证据与清理

- 截图和断言报告保存到 `output/playwright/`，记录 URL、视口、主题和数据模式。
- 关闭测试浏览器上下文；保留现有 `4173`、`5173` 服务，不重启生产服务。
- 隔离上下文的数据无需迁移；人工浏览器检查后恢复原主题、语言及草稿，不清空真实存储。
