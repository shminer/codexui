# Mermaid 图表展示与交互

## 前置条件

- 使用已有运行中的应用；主聊天和 `/btw` 侧边对话均可正常收发消息。
- 准备一条普通代码块、一条错误 Mermaid 代码块，以及以下有效图表。请让回复在输出完图表后继续输出一段文字，以检查生成状态。

````markdown
```mermaid
flowchart LR
  A[开始] --> B{是否继续}
  B -->|是| C[完成]
  B -->|否| A
```

```mermaid
sequenceDiagram
  participant A as 用户
  participant B as 服务
  A->>B: 请求
  B-->>A: 响应
```
````

| 错误语法 | 展示错误 Mermaid 代码块 | 显示绘图失败提示与原始源码，仍可复制；后续有效图表正常绘制 |

| 全屏回退复制 | 在剪贴板 API 不可用或权限被拒绝的浏览器上下文中，全屏查看图表后复制源码；主窗口和独立侧窗各执行一次 | 回退文本框始终位于当前弹层内，复制内容正确；文本框清理后焦点返回复制按钮 |
| 清理 | 绘图期间切换线程，关闭或收起侧窗，多次打开关闭弹层 | 不出现旧图覆盖新图、残留遮罩、残留临时 SVG 或拖动事件 |

回退复制场景可在待测窗口的开发者工具控制台临时设置。先模拟 API 缺失，再模拟 API 拒绝，每次设置后回到图表全屏点击复制，并将内容粘贴到文本编辑器确认。独立侧窗须在该侧窗自己的控制台设置。

```js
Object.defineProperty(navigator, 'clipboard', { configurable: true, value: undefined })
// 完成缺失场景后，设置拒绝场景。
Object.defineProperty(navigator, 'clipboard', {
  configurable: true,
  value: { writeText: () => Promise.reject(new Error('Clipboard permission denied')) },
})
```

## 性能检查

- 无 Mermaid 的聊天不加载 Mermaid 库；图表接近可视区且回复结束后才加载和绘制。
- 缩放、拖动、打开及关闭弹层只改变当前视图，不重新绘图，不增加聊天 API 请求。
- 同一图表不因其他消息流式更新而重新绘制；多图渲染依次执行，主题互不覆盖。
- 带有效 `viewBox` 的图表直接读取尺寸；缺失时仅在 SVG 挂载后调用一次 `getBBox()`，缩放、拖动不重新测量。
- Plan 的 Markdown 解析缓存最多保留 300 项，按项目目录和正文区分；流式中间结果不入缓存。
- 指定会话实测：缩放、拖动、复制及全屏切换后 SVG 标识保持不变，图表交互新增 API 请求为 0；期间另有 1 次既有 `thread/list` 后台刷新。
- 浏览器帧率、首次加载耗时和产物体积未测量。
